# Design references

- [uni-robot-agent](https://github.com/Open-RUA/uni-robot-agent): shared typed tools and separation of agent, orchestration, services and robot backends.
- [PyRUA-Lean](https://github.com/DAGroup-PKU/PyRUA-Lean): code-as-policy and bounded action primitives with local result checks.
- [PyRUA-DataFarm](https://github.com/DAGroup-PKU/PyRUA-Lean/tree/DataFarm): recent video/demo-to-action-labelled-data direction; treated as a later extension.
- [ENPIRE](https://github.com/NVlabs/ENPIRE): fixed reset/verifier/safety contract and evidence-driven policy-side experiments.
- [ASPIRE](https://github.com/NVlabs/ASPIRE): refine a versioned skill library and promote only independently verified skills.
- [Robot-Use Agents unified harness](https://arxiv.org/abs/2611.01560): recent shared runtime, executor and monitor design.
- [Agentic World Action Models](https://arxiv.org/abs/2610.30136): combines code planning, future video prediction and robot actions.
